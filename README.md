# NOVUS-OS Enterprise Panel
![NOVUS-OS Banner](ссылка_на_красивую_картинку_с_логотипом)

Official compiled release of the NOVUS-OS Control Plane.

## Repository Role
Public release channel for operators and client installations.
Contains production-ready compiled panel artifacts.

## Build Origin
Private source repository: SGC-NOVUS/panel-core.

## Release Flow
1. Development is performed in SGC-NOVUS/panel-core.
2. CI/CD builds release artifacts.
3. Release is published to SGC-NOVUS/panel.

## Update Consumption
NOVUS-OS Panel checks this repository for updates on a daily schedule.

## Security
Report vulnerabilities through a private security channel before public disclosure.
